# 伝奇原稿の通し編集

日本語の伝奇小説・ライトノベル原稿に、編集者としてダメ出しをするための手順。一場面ずつの点検ではなく、幕や話をまたいでしか見えない傷（数の食い違い、モチーフの混線、締めの型の偏り、主題の言いすぎ、反応の型の収束、口調の揺れ）を見つけることに重点を置く。文体の作法そのものは `nasu-style-prose` スキルに従い、このスキルはその点検と、幕をまたぐ点検を受け持つ。

## 原則

- **数えられるものは機械で数える**。書いた本人（自分を含む）の自己申告の表を信じない。前回の表と実測が食い違ったら、ダメ出しの中ではっきり認める
- **数えるのは語ではなく形**。「答えなかった」だけを数えると「顔を上げなかった」「口を閉じた」を取りこぼす。癖は、同じ働きをする言い回しの集まりとして拾う。数えた結果が少なすぎると感じたら、まず検出の網の目を疑う
- **作者の手直しは、いちばん強い指摘として読む**。作者が原稿を直していたら、直した箇所を一つずつ取り出し、何の型の直しかを言葉にし、同じ型を原稿全体（前の話も含む）から探す。作者が直した箇所だけを直して終えない
- **「効いていない」と言われたら、検出から直す**。作者に「まだ残っている」と言われたら、その例を正規表現に足してスクリプトを走らせ直し、同じ型を全部拾ってから直す
- **証拠を添える**。指摘には必ず、該当する本文の引用か、数えた数を付ける
- **重さの順に並べる**。致命的（直さないと話が成り立たない）、重い（作品の質を落とす）、文章の癖、良かった点（残すもの）の順
- **直し方まで書く**。指摘だけで終えず、具体的な直し方を一つ以上示す
- 良かった点は三つまで。直すときに壊してはいけない箇所として挙げる
- **作者の指示を優先する**。作者が明示的に頼んだ構成（「エピローグを拡張して」など）が一般的な目安（山場のあとの締めは二つまで、など）とぶつかるときは、指示に従ったうえで、目安とのずれを一行で知らせるにとどめる

## 手順

### 0. 作者の手直しを読む

ドキュメントの原稿なら、自分が最後に書いた版からの変更を取り出す（Claude Docs なら `view` の `sinceRev`）。作者が書き換えた語を前後で並べ、型に名前をつける（例：「やまん→やまない」「空いておる→空いている」なら、主人公の台詞から老人語の否定と「おる」を抜く直し）。型ごとに、手順2の口調・否定・反応の検出で原稿全体から同じものを拾い、ダメ出しの最初に「作者の手直しから読み取った方針」として書く。読み取りが確かでないときは、その旨を一行添える。

### 1. 本文をファイルにする

幕ごとに本文をテキストファイルに保存する。場面の区切りは `---` だけの行にする。会話の履歴にしかない原稿は、履歴から取り出してファイルにする（手で打ち直さない）。ドキュメントに置いた原稿は、あとから入れた修正を取りこぼさないよう、最新版から取り出す。

### 2. 機械で数える

次のスクリプトを作業ディレクトリに保存し、幕ごと、および話全体で走らせる。監視語は作品ごとに決める（主人公の肩書きの数字、怪異の名、色の語、繰り返しやすい形容詞など）。沈黙の反応、接続の語、否定からの逆接、口調の印は、指定しなくても毎回数える。

```python
"""伝奇原稿の機械的カウント。使い方: python3 prose_count.py 原稿.txt 監視語1,監視語2
場面は '---' だけの行で区切る。結果は候補の一覧で、最終判断は人が読んで行う。"""
import re,sys
text=open(sys.argv[1],encoding='utf-8').read()
watch=[w for w in (sys.argv[2].split(',') if len(sys.argv)>2 else []) if w]
ENDS=set('いきしてりみびちにもとがで')
# 沈黙・不反応の型（語ではなく形で拾う）
REACT=re.compile(r'答えなかった|答えず|返事をしなかった|何も言わ(?:ず|なかった)|黙って|黙った|口を閉じ|言いかけ(?:て、やめ|た)|顔を上げなかった|振り向かなかった|振り返らなかった|動かなかった|(?:それ以上|何も)(?:は)?(?:言わ|訊か|聞か)なかった|何も訊かず')
LINK=['それから','しばらく','やがて']
NEG=r'(?:ない|なかった|ません|ではなく|でもない|ず(?=[、。])|ん(?=[。、」な]))'
CONTRA=r'^(?:だが|しかし|けれど|けれども|でも|それでも|ただ|代わりに|むしろ)'
# 方言・老人語・書生語の印（口調台帳用）
VOICE=re.compile(r'おる|おった|おらん|[^いせ]ん(?=[。、」]|のでな|のです|かね|な」)|よう(?=似|分か|知|来)|なすっ|じゃろ|とる|とった|ですな|でしてな|たまえ')
def sents(s): return [x for x in re.split(r'(?<=[。！？」])',s) if x.strip()]
def triples(s):
    out=[]
    for sent in sents(s):
        segs=[x for x in sent.split('、') if x.strip()]
        for i in range(len(segs)-2):
            a,b=segs[i].strip(),segs[i+1].strip()
            if a and b and a[-1]==b[-1] and a[-1] in ENDS:
                out.append(sent.strip()); break
        if re.search(r'([^、。も]{1,8}も){3}',sent): out.append(sent.strip())
    return list(dict.fromkeys(out))
def negturns(s):
    """否定からの逆接・言い直しの候補"""
    ss=[x.strip() for x in sents(s)]; out=[]
    for i,x in enumerate(ss):
        if re.search(r'ではない|ではなく|のではなかった|でもない',x): out.append(('XではなくY',x))
        if re.search(r'ても[^。」]*'+NEG,x): out.append(('〜ても〜ない',x))
        if re.search(NEG+r'[^。」]*[^ら]が、',x): out.append(('否定＋が、',x))
        if re.search(r'[^せ]ず、',x): out.append(('〜ず、〜',x))
        if re.search(r'^(?:だが|しかし)[^。]*'+NEG,x): out.append(('だが＋否定',x))
        if i+1<len(ss) and re.search(NEG+r'[。」]?$',x):
            n=ss[i+1].lstrip('「')
            if re.search(CONTRA,n) or re.search(r'だけ[がは]',n): out.append(('否定。→逆接',x+n))
            elif re.search(r'^[^。]{0,6}(?:は|が)',n) and len(x)<20: out.append(('否定。→肯定の言い直し?',x+n))
    return out
scenes=re.split(r'\n-{3,}\n',text)
total={w:0 for w in watch+LINK}; rtotal=0; ntotal=0
for i,s in enumerate(scenes,1):
    paras=[p.strip() for p in s.split('\n') if p.strip() and not p.lstrip().startswith('#')]
    narr=[p for p in paras if not p.startswith(('「','『'))]
    one=[p for p in narr if len(re.findall(r'[。！？]',p))<=1]
    neg=negturns(s); tri=triples(s); react=REACT.findall(s)
    voice=[(m.group(),p) for p in paras if p.startswith('「') for m in VOICE.finditer(p)]
    rtotal+=len(react); ntotal+=len(neg)
    print(f'--- 場面{i}: 段落{len(paras)} 一行段落{len(one)} 否定→逆接候補{len(neg)} 三つ並び候補{len(tri)} 沈黙の反応{len(react)}')
    for p in one: print('   一行:',p[:40])
    for k,n in neg: print(f'   否定[{k}]:',n[:60])
    for t in tri: print('   三つ?:',t[:60])
    for m in REACT.finditer(s): print('   反応:',s[max(0,m.start()-15):m.end()+5].replace('\n',' '))
    for w,p in voice: print(f'   口調[{w}]:',p[:50])
    for w in watch+LINK:
        c=s.count(w); total[w]+=c
        if c: print(f'   {"接続" if w in LINK else "監視語"} {w}: {c}')
    print('   場面末:',paras[-1][:40] if paras else '')
print('=== 合計:',total)
print('=== 沈黙の反応（目安：一話に三回まで）:',rtotal)
print('=== 否定→逆接の候補:',ntotal)
```

あわせて、全幕をつなげたファイルで、漢字・カタカナを含む四〜七字の語の出現回数を数え、四回以上出る語を一覧にする。固有名詞を除いた残りが、作者の手癖の候補になる（例：「乾いた」「沈んで」「の向こう」「という顔をした」「何も言わず」「たまま言った」）。

文字の取り違え（似た字形の別の漢字が入る事故。例：「栞」が「栧」、「淹」が「淒」、「桟」が「桁」、「顔」が「顏」）は、カウントでは見つからない。原稿に出てくる小物や動作の語を一覧にし、ドキュメント上で検索して、正しい字で出ているか確かめる。自分が書き足した執筆メモの文も同じように確かめる。

**読み方の注意**

- 一行段落は、地の文が続く区間での決め打ちの一行だけを基準（一場面に三、四か所）と比べる。会話の多い場面で台詞のあいだに挟まる一文の地の文は、数が増えても問題ないことが多い
- **否定からの逆接**は、型を問わず一話に二、三か所までを目安にする。拾う型は「XではなくY」「〜ない。だが〜」「〜ても〜ない」「〜ず、〜」「〜ない。〜だけが」「だが、〜なかった」、および「〜ない。」のあとに肯定で言い直す二文。直し方は、否定の側を削って肯定だけで言い切る、動作で見せて台詞から理屈を抜く、の二つが基本（例：「古本屋は客の名前を覚えん。だが、帳面には書く」→台詞を削り、帳面に名前を書きつける動作だけを残す）。場面の結びの一文や、前の話と対になる意図した否定は残してよいが、残す理由をダメ出しに書く
- 沈黙の反応のうち「動かなかった」は、物の描写（刃が動かなかった）を拾うことがある。人物の反応かどうかを読んで判断する
- 三つ並びと否定の候補は候補にすぎない。本文を読んで、本当に既定値の癖になっているものだけを指摘する
- 実測の数は、ダメ出しの本文に表で載せる

### 3. 台帳をつける

幕をまたぐ傷は、台帳をつけないと見えない。次の九つを作る。

1. **時系列の台帳**：各場面の日付と時刻、前の場面からの経過時間。刊行物の発行頻度、昼夜、季節、営業時間と矛盾しないか。場所を移る場面では、距離と所要時間（例：礼拝堂から部室まで徒歩四十分）を書き、誰が先に着くか、待っていた人物の待ち時間（「三時間湯を沸かしていた」）が合うかを確かめる
2. **数と因果の台帳**：被害者、怪異の筋、武器、手がかりなど、数えられるものの数を幕ごとに書き出す。仕掛けが解かれる場面で、その数がすべて回収されているか（例：束が四本と書いたのに、解く場面で守衛の分を含めた五人分が戻っている、という食い違い）
3. **伏線と回収の台帳**：前の幕で置いた伏線と、どこで回収したか。回収されないまま残すものは、意図して残すのか、忘れたのか
4. **知識の台帳**：誰が、いつ、何を知ったか。視点人物が知らないはずのこと（他人の経歴、別の場面の出来事）を地の文に書いていないか。「士希はそれを見なかった」のように、視点人物が見ていないことを語り手が告げる書き方も、視点の踏み外しとして拾う
5. **物と位置の台帳**：場面の境目で、扉の開閉、明かり、持ち物、脱いだ物、壊れた物の状態が引き継がれているか
6. **モチーフの台帳**：作品の看板の絵（例：持ち手のいない労働）が、どの出どころに属するか。同じ絵を、別の人物の魔術や別の怪異に使っていないか。使うと、読者は同じ仕組みだと読み違える
7. **ルールの台帳**：作中で言い切った能力の制限、人物の戒め、組織の掟（「人に結ばれたものは解かない」「刻印を断った代行者は処断」）を書き出し、前の話の場面と食い違わないか、その話の中で掟を破る人物に理由が書かれているかを確かめる
8. **手がかりの累計台帳**：正体を隠している人物ごとに、ほのめかしの手がかりを話をまたいで数える。一場面一つを守っていても、一話で三つを超えると告白になる
9. **口調の台帳**：主要人物ごとに、一人称、二人称、文末（「〜だ」「〜でしてな」「〜たまえ」）、方言や老人語の印（「おる」「〜ん」「よう似た」「なすった」「とる」）を、前の話と今の話で並べる。スクリプトの「口調」の行を人物に振り分けて作る。決めた口調から外れた台詞を一覧にし、同じ人物の台詞が話の中で揺れていないか、前の話と食い違っていないかを確かめる。作者が台詞を直していたら、その直しを口調の決まりとしてこの台帳に書き込み、前の話にも同じ揺れが残っていればダメ出しで知らせる。年配の脇役の老人語のように、人物の印として正しいものは残す

### 4. 話全体を見る

- **締めの集計**：全場面の最後の一文を並べ、型（決め台詞、像、動作の途中、会話、後日談）と、誰の台詞で終わるかを数える。同じ人物の決め台詞で締める場面が続いていたら、指摘する
- **主題の言及回数**：作品の主題を、語り手か人物がはっきり言葉にしている箇所を数える。一話に一度が目安。二度目以降は、前のものより強い場面でなければ削る。同じ場面で二人が続けて主題を言っていたら、一つに絞る
- **反応の集計**：沈黙の反応をスクリプトの型で数え、人物ごとに振り分ける。一話で三回を超えたら、人物の反応の型が一つに収束している。残すものは、黙ること自体に意味がある場面に限る
- **主人公の傷**：主人公の根本の傷や過去（追放、逃げたこと、など）に、その話が一度でも触れているか。触れない話が続くと、事件は主人公にとって他人事に見える
- **登場人物の出番と決断**：主要人物ごとに、その話での台詞の数と、自分で決めて動いた場面を表にする。決断が一つもない主要人物がいたら指摘する
- **敵の動機の筋**：敵や追手が、言ったことと違う行動をとる場面（命令を果たさずに引く、など）に、理由と代償が書かれているか
- **幕の長さの比**：幕ごとの文字数を数える。山場の幕が導入の幕より短いときは、意図したものかを問う
- **山場のあとの締めの重なり**：山場のあとに来る後日談、余韻、コーダの数を数える。三つ以上あると、山場の余韻が薄まる（作者が拡張を頼んだ場合は、指示を優先して一行で知らせる）
- **約束と回収**：冒頭や幕切れで人物が口にした目的（「宛名を見に行こう」）が、話の中で回収されているか

### 5. ダメ出しを書く

次の順で書く。

1. **作者の手直しから読み取った方針**：手順0で取り出した型と、同じ型が残っていた箇所の数
2. **致命的なもの**：成り立たない因果、数の食い違い、時系列の矛盾、モチーフの混線、ルールの食い違い
3. **重いもの**：主人公の傷に触れていない、人物の決断がない、敵の動機の欠落、主題の言いすぎ、反応の型の収束、口調の揺れ、締めの型の偏り、幕の長さの釣り合い
4. **文章の癖**：実測の表（一行段落、否定からの逆接、三つ並び、監視語、沈黙の反応、接続の語、手癖の語、口調の外れ）と、直すべき箇所の引用
5. **自己申告との食い違い**：前回の表と実測が違ったら、ここで認める。検出の網の目が粗かったせいなら、何を取りこぼしていたかも書く
6. **良かった点**：残すもの三つまで
7. **直す順番**：優先順位をつけた短い一覧

各指摘には「どこで（幕・場面）」「何が（引用か数）」「なぜ困るか」「どう直すか」を入れる。

## 直したあと

直しを頼まれたら、全部の指摘を反映して書き直し、同じスクリプトと台帳で数え直す。数え直した表を、直した原稿に添える。報告する数は、直したあとの原稿をもう一度ファイルに取り出して数えたものに限る（直す前の見込みの数を書かない）。新しく見つかった傷の型は、このスキルのスクリプトの正規表現か台帳に書き足すことを提案し、文体の作法にかかわるものは `nasu-style-prose` スキルにも書き足すことを提案する。
